INTEGRATION GUIDE

Your login. An Azimap map.

This sample uses ASP.NET Core, but the integration works with any backend that can make authenticated HTTP requests. Users sign in to your application. Your backend holds the API key and checks permission before requesting read sessions or single-use write tokens. Users do not need an Azimap account.

1. Configure Cloud access

Create or select an API key in Azimap Cloud. Limit it to the maps, layers and operations you need. Allow this application's browser origin and your backend's actual egress IP in the key's whitelist.

Copy appsettings.example.json to appsettings.Local.json beside this sample's project. Replace the key, map ID, layer IDs and sample password. The local file is ignored by Git. Keep secrets on the server.

{
  "Azimap": {
    "IssuerBaseUrl": "https://app.azimap.com/",
    "ApiBaseUrl": "https://api.azimap.com/",
    "AssetBaseUrl": "https://app.azimap.com/azimap-runtime/",
    "LayerContentApiUrl": "https://tiles.azimap.com/",
    "ApiKey": "YOUR_SERVER_API_KEY",
    "MapId": 123,
    "LayerIds": [
      456
    ]
  },
  "Sample": {
    "Username": "demo",
    "Password": "REPLACE_WITH_YOUR_OWN_PASSWORD",
    "AllowEditing": false,
    "AllowExport": false
  }
}

These are the production Azimap Cloud URLs. Environment variables override file settings; use double underscores, for example Azimap__ApiKey.

2. Run your application

dotnet run -f net10.0 --no-launch-profile --urls http://localhost:5098

Open localhost:5098 and sign in using your configured sample account. Restart after changing settings, then sign out and sign back in to refresh grants.

3. Try sessions and editing

  • Use Renew session or leave the map open to observe automatic renewal.
  • For editing, use a designated test layer and set Sample:AllowEditing=true. Your API key and map must permit the requested operations. Browser settings alone cannot grant permission.
  • Before a supported save, the library requests a single-use write token through your authenticated backend. Your backend checks the requested layers and operations. The browser then sends the mutation directly to Azimap.
  • Failed renewal suspends interaction and retains unsaved edits. Resolve unsaved work before reloading after a permission change.
  • Signing out closes this map and prevents further issuance. Already-issued tokens elsewhere can remain usable until expiry or parent-key revocation.

Connect your own authentication

Use your existing login and live permission service. The sample's one-account login and fixed claims demonstrate the flow; they do not track subsequent permission changes. Check current permission on every issuance, including every layer and operation in a write request. Layer scope does not provide record-level authorization.

The adapters expose authenticated GET /azimap/csrf, POST /azimap/maps/{mapId}/session and POST /azimap/maps/{mapId}/write-token in your application. Both POSTs require X-CSRF-Token. Initialize the map with auth: Azimap.customerBackend('/azimap') to handle CSRF, session renewal and supported write-token acquisition.

Your backend calls https://app.azimap.com/api/embed/sessions and https://app.azimap.com/api/embed/write-tokens using its server-held API key. The browser must never receive that key. Read sessions last at most five minutes. Write tokens last at most two minutes, never outlive their read session and authorize one HTTP mutation request. Do not automatically retry uncertain writes.

Troubleshooting

  • Runtime failed to load: check access to https://app.azimap.com/azimap-runtime/ and the browser console for blocked scripts or network requests.
  • 401: sign in again; if it persists, check the server-held API key.
  • 403: check user permissions, key grants, map/layer IDs, browser origin and backend egress IP.
  • 404: verify the issuer URL and availability of the embed session service for your Cloud integration.
  • 429: wait before trying again; login and issuance have rate limits.
  • 503 or network error: check connectivity to Azimap Cloud. Do not automatically resubmit an uncertain save.
